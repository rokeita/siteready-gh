# SiteReady GH

A browser-only website preview generator for Ghanaian small businesses.

## Why it exists

Many local businesses rely on WhatsApp or Instagram alone. SiteReady GH helps a developer create a polished one-page sample in minutes, so the business owner can see what their website could look like before committing.

## Current MVP

- Business name and short description
- Service cards from a simple list
- Brand colour picker
- WhatsApp call-to-action link
- Responsive one-page preview
- No database, cloud account, API key, or payment card required

## Run it

Open `index.html` in any modern browser. The app is a single static file.
